# Детерминированные операции workflow

Полные команды, случаи отказа и границы полномочий находятся в каноническом
разделе [сценариев жизненного цикла](lifecycle-cookbook.md#deterministic-workflow-recipes).
Используйте этот включённый в пакет раздел для создания и просмотра артефактов
и ограниченного локального продолжения. Экономия токенов или денег не обещается.
