# Из внешней задачи в черновик спецификации

Внешняя задача служит входными данными и не даёт полномочий на исполнение.
Скилл `issue-to-spec` переводит заявку, сообщение об ошибке, запрос из чата
или данные трекера в черновые материалы планирования ALK.

Результат остаётся только черновиком:

- `sourceTrusted: false`;
- `requiresReview: true`;
- `freezeBlocked: true`;
- `executionAuthorized: false`.

Сохраните идентификаторы исходных задач, предполагаемые требования, проверки
приёмки, ограничения, сведения о рисках, отсутствующие доказательства и вопросы,
которые мешают зафиксировать план. Затем передайте черновик в
`agent-first-planning` и `audit-agent-plan`.

Для сообщений об ошибках черновик может рекомендовать необязательный профиль
Bug Forensics. Воспроизведение ошибки и доказательства исправления всё равно
должны входить в проверенный план.
