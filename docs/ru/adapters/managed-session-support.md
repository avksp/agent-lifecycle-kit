# Поддержка управляемых сессий адаптеров

Поддержка управляемых сессий отделена от зрелости адаптера и от отображения
прогресса. Она показывает, может ли ALK создать receipt управляемой сессии и
заявляет ли дескриптор безопасный профиль нативного запуска.

| Адаптер | Управляемая сессия | Профиль нативного запуска | Примечание |
| --- | --- | --- | --- |
| Codex | Поддерживается | `WRAPPER_ONLY` | Используй `adapter run` или обёртку хоста для lifecycle proof. |
| Claude Code | Поддерживается | `WRAPPER_ONLY` | Нативный запуск остаётся ответственностью хоста. |
| Cursor | Поддерживается | `WRAPPER_ONLY` | Это не меняет зрелость Cursor. |
| Gemini CLI | Поддерживается | `WRAPPER_ONLY` | Нативный argv-запуск не заявляется. |
| Goose | Поддерживается | `WRAPPER_ONLY` | ACP по-прежнему проверяется отдельной пробой. |
| Grok Build | Поддерживается | `WRAPPER_ONLY` | Провайдер и модель остаются локальной ответственностью хоста. |
| Hermes | Поддерживается | `WRAPPER_ONLY` | Установка skill сама по себе не является lifecycle proof. |
| Kimi Code | Поддерживается | `WRAPPER_ONLY` | Это не меняет зрелость Kimi. |
| OpenCode | Поддерживается | `WRAPPER_ONLY` | Телеметрия хоста остаётся вне core. |
| OpenInterpreter | Поддерживается | `WRAPPER_ONLY` | Учётные данные провайдера остаются локальными для хоста. |
| Pi | Поддерживается | `WRAPPER_ONLY` | Учётные данные провайдера остаются локальными для хоста. |
| Qwen Code | Поддерживается | `WRAPPER_ONLY` | Доказательство жизненного цикла требует управляемой ALK-команды. |

Общая управляемая команда:

```bash
agent-lifecycle adapter run \
  --adapter <adapter-id> \
  --state <workflow-state.json> \
  --manifest <plan.manifest.json> \
  --lock <plan.lock.json> \
  --task <task-id>
```

`WRAPPER_ONLY` означает, что ALK может связать сессию с доказательством
workflow и показать прогресс из состояния ALK, но core ALK не заявляет
безопасный запуск нативного CLI этого адаптера.

Этот статус не заявляет безопасный запуск нативного CLI и не делает установку
plugin доказательством жизненного цикла.
