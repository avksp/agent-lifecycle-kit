# Поддержка управляемых сессий адаптеров

Поддержка управляемых сессий является отдельным измерением уровня поддержки
адаптера и отображения прогресса. Она показывает, может ли ALK создать подтверждение управляемой
сессии и заявляет ли дескриптор безопасный профиль прямого запуска.
Основная [матрица поддержки адаптеров](support-matrix.md) показывает текущее
значение `managedLaunch.status`; эта страница объясняет границу.

| Адаптер | Управляемая сессия | Профиль прямого запуска | Примечание |
| --- | --- | --- | --- |
| Codex | Поддерживается | `WRAPPER_ONLY` | Используй `adapter task start`, `adapter run` или обёртку хоста для подтверждения жизненного цикла. |
| Claude Code | Поддерживается | `WRAPPER_ONLY` | Прямой запуск остаётся ответственностью хоста. |
| Cursor | Поддерживается | `WRAPPER_ONLY` | Подтверждение жизненного цикла использует управляемый маршрут ALK. |
| Gemini CLI | Поддерживается | `WRAPPER_ONLY` | Для связанного процесса используется маршрут ALK через проверенный профиль. |
| Goose | Поддерживается | `WRAPPER_ONLY` | ACP по-прежнему проверяется отдельной пробой. |
| Grok Build | Поддерживается | `WRAPPER_ONLY` | Провайдер и модель остаются локальной ответственностью хоста. |
| Hermes | Поддерживается | `WRAPPER_ONLY` | Для подтверждения жизненного цикла используются команды ALK. |
| Kimi Code | Поддерживается | `WRAPPER_ONLY` | Подтверждение жизненного цикла использует управляемый маршрут ALK. |
| OpenCode | Поддерживается | `WRAPPER_ONLY` | Телеметрия хоста остаётся вне ядра. |
| OpenInterpreter | Поддерживается | `WRAPPER_ONLY` | Учётные данные провайдера остаются локальными для хоста. |
| Pi | Поддерживается | `WRAPPER_ONLY` | Учётные данные провайдера остаются локальными для хоста. |
| Qwen Code | Поддерживается | `WRAPPER_ONLY` | Доказательство жизненного цикла требует управляемой ALK-команды. |

Общая команда приёма задачи:

```bash
agent-lifecycle adapter task start \
  --adapter <adapter-id> \
  --file task.md
```

Обычный текст и Markdown возвращают черновой вход, который требует проверки.
Чтобы сразу начать управляемую работу, передайте зафиксированный
`agent-adapter-task-run-request.v1` или зафиксированный manifest с параметрами
привязки к рабочему циклу.

Общая команда управляемого запуска:

```bash
agent-lifecycle adapter run \
  --adapter <adapter-id> \
  --state <workflow-state.json> \
  --manifest <plan.manifest.json> \
  --lock <plan.lock.json> \
  --task <task-id>
```

`WRAPPER_ONLY` означает, что ALK связывает сессию с подтверждением жизненного
цикла и показывает прогресс из состояния ALK через управляемые команды или
проверенную обёртку. Проверенные локальные профили описывают маршрут
процесса для адаптеров с принятыми подтверждениями запуска. Установка плагина и
подтверждение жизненного цикла фиксируются отдельно.
