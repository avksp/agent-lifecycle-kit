# Границы обновления через хост

[English](https://github.com/avksp/agent-lifecycle-kit/blob/main/docs/adapters/plugin-updates.md)

ALK даёт рекомендации. Установкой, заменой кеша, разрешениями и загрузкой сессии
владеет хост. Assessment, рецепт, JSON-квитанция и совпадение номера версии не
разрешают изменять native-файлы.

| Режим или операция | Текущее поведение |
| --- | --- |
| off | Нет автоматической работы или native dispatch. |
| manual | Явная проверка метаданных и планов. |
| notify | Без квалифицированного trigger не поддерживается; входной флаг его не доказывает. |
| ask | Показывает неисполняемый ручной рецепт и пробелы, если выбранные входы не изменились. |
| safe-auto | Не поддерживается: нет подтверждённой безопасной границы, полного scope и recovery. |
| install | Отказ до native dispatch. |
| reconcile | Наблюдает текущий Python runtime отдельно от заявленных installed/loaded версий. |

Это ограничения операции обновления, а не всей интеграции адаптера с ALK.
API не назначает модель или провайдера. Новый установщик, native executor,
планировщик и форк хоста не создаются.

Используйте одну политику запроса для check, assessment и offer. Изменение
политики, цели, commit или выбранного файла требует новой оценки. Offer повторно
проверяет явные хеши в пределах 32 планов, 64 файлов на план, 256 КиБ на файл и
восьми МиБ суммарно. Активный, приостановленный, неизвестный или frozen-запуск
без state требует отложить активацию. Завершённая история сохраняется.

```sh
agent-lifecycle plugin-update offer --request request.json --assessment impact.json --out offer.json
agent-lifecycle plugin-update install --request request.json --offer offer.json --out refusal.json
agent-lifecycle plugin-update reconcile --request observations.json --out identities.json
```

Для заявленного Codex хоста ALK может показать документированные формы команд
marketplace remove, add с точным ref, plugin add и plugin list. Это
**неисполняемый ручной рецепт**, а не квалифицированная транзакция или
рекомендация установки. Остальные неподтверждённые хосты получают явный отказ;
скрытого переключения адаптера нет.

В инструкции первой установки используется shorthand marketplace
`avksp/agent-lifecycle-kit`. Рецепт только для обновления удаляет существующий
marketplace с тем же именем, добавляет явный Git URL
`https://github.com/avksp/agent-lifecycle-kit.git` с точным `--ref` и запрашивает
JSON-вывод. Это формы разных операций: первая регистрация и неисполняемый рецепт
замены прежней записи. Они не квалифицируют операцию, её глобальный scope или
пригодность rollback.

Перед отдельным ручным обновлением проверьте актуальные help/version хоста,
повторно разрешите точные tag/commit и получите разрешение на фактический scope.
Удаление marketplace и переустановка могут затронуть другие проекты пользователя.
Локальный список планов не доказывает полноту глобального scope. ALK не сканирует
чужие проекты и сессии, чтобы объявить его полным.

Сохраняйте исходные plan, lock, state, расходы, попытки и часы. Новая версия
плагина не разрешает перепись frozen authority. Сохраните пригодный проверенный
runtime или выполните reviewed amendment штатного lifecycle. Старый кеш или
резервная копия не доказывают возможность рабочего rollback.

После внешнего обновления перезапускайте или перечитывайте сессию только
поддерживаемым способом хоста. Проверяйте установленные файлы и фактически
используемый runtime отдельно. Переданные вызывающим loaded-метки остаются `DECLARED`:
совпадение значений не подтверждает активацию. Отсутствие доказательств —
`UNKNOWN`, расхождение — `DRIFT`. Reconcile не меняет lifecycle и не даёт прав.

Сбой или timeout native-обновления может оставить неизвестный частичный эффект.
Сохраните квитанцию и проверьте состояние перед новым действием. Не повторяйте
операцию вслепую и не обещайте сохранение кеша. ALK не блокирует независимый
фоновый updater хоста. См. [влияние на планы](../reference/plugin-updates.md).
