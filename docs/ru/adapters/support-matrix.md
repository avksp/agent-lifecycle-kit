# Матрица поддержки адаптеров

Матрица фиксирует заявление исходного дерева о поддержке адаптеров. Она не
заменяет локальные проверки: перед использованием нужно запускать `diagnose`,
`adapter validate` и `adapter inspect`.

| Хост | Зрелость | Что это значит |
| --- | --- | --- |
| Codex | `VERIFIED` | Проверен для Codex CLI 0.145.0. |
| Claude Code | `VERIFIED` | Проверен для Claude Code 2.1.220. |
| OpenCode | `VERIFIED` | Проверен для OpenCode CLI 1.18.9. |
| Hermes | `VERIFIED` | Проверен для Hermes Agent v0.19.0. |
| Qwen Code | `VERIFIED` | Проверен для Qwen Code 0.21.0 на локальной связке провайдера и модели. |
| Cursor | `EXPERIMENTAL` | Локальный осмотр проходит, но подтверждений из реального запуска недостаточно. |
| Gemini CLI | `EXPERIMENTAL` | Проверка реальным вызовом ограничена текущим уровнем Gemini Code Assist. |
| Goose | `VERIFIED` | Проверен для Goose 1.45.0 на локальной связке провайдера и модели; одобрение публичного каталога не заявлено. |
| Kimi Code | `EXPERIMENTAL` | Нужен настроенный провайдер и алиас модели. |
| Grok Build | `VERIFIED` | Проверен для Grok Build 0.2.117 на локальной связке провайдера и модели; одобрение публичного каталога не заявлено. |
| OpenInterpreter | `VERIFIED` | Проверен для `interpreter` 0.0.34 на локальной связке провайдера и модели; реальная проверка совместимости, калибровка, ограничения среды и подтверждение жизненного цикла прошли локально, одобрение публичного каталога не заявлено. |
| Pi | `VERIFIED` | Проверен для Pi 0.83.0 на локальной связке провайдера и модели; реальная проверка совместимости, калибровка, ограничения среды, проверка env-файла и подтверждение жизненного цикла прошли локально, одобрение публичного каталога не заявлено. |

`VERIFIED` относится только к указанному диапазону хоста и не означает
публичное одобрение каталога, npm-публикацию или готовность других версий.

Подтверждения проверки возможностей — это детектор расхождений для реальной
совместимости. План строится из `agent-adapter-capability-manifest.v1`, не
запускает реальные вызовы, не меняет зрелость и не заявляет промышленную
готовность. Проверка подтверждений сравнивает артефакты реального хоста с
планом и падает при пропущенной запланированной операции, синтетическом
повторе для операции, требующей реального запуска, или обходе оболочки
host-protocol.

Подтверждения песочницы используют только `agent-sandbox-receipt.v1`. Частичные
ограничения дерева процессов и границы прокси для учётных данных записываются в
деталях артефакта; значения секретов и полные пути к приватным env-файлам
недопустимы.
