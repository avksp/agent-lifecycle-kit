# Краткая поддержка Kimi Code

Начальная зрелость: `EXPERIMENTAL`.

Не заявляйте `VERIFIED`, одобрение публичного каталога или промышленную
готовность, пока для конкретного диапазона версий хоста не пройдут проверка
реального хоста, калибровка расхода, проверка маскирования и обновление матрицы
поддержки.
