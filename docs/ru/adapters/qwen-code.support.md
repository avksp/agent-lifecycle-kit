# Краткая поддержка Qwen Code

Текущий уровень поддержки: `VERIFIED`.

Поддержка Qwen Code охватывает Qwen Code `0.21.0` на проверенной локальной
связке провайдера и модели. Совместимость исходного дерева и область публикации
описаны в связанных артефактах.

Авторитетные сведения находятся в:

- `docs/adapters/qwen-code.md`;
- `docs/adapters/support-matrix.md`;
- `docs/adapters/evidence/qwen-code-host-local-live-2026-07-29.md`.

Для расширения поддержки на другую версию Qwen Code, провайдера, модель или
канал публикации добавьте ограниченную проверку реального хоста, калибровку
расхода, проверку маскирования, обновление матрицы поддержки и финальное
подтверждение жизненного цикла.
