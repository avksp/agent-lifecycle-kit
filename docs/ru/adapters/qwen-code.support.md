# Краткая поддержка Qwen Code

Текущая зрелость: `VERIFIED`.

Qwen Code подтверждён только для Qwen Code `0.21.0` на проверенной локальной
связке провайдера и модели. Это заявление о совместимости исходного дерева, а
не одобрение публичного пакета, публичного каталога или промышленная готовность.

Авторитетные сведения находятся в:

- `docs/adapters/qwen-code.md`;
- `docs/adapters/support-matrix.md`;
- `docs/adapters/evidence/qwen-code-host-local-live-2026-07-29.md`.

Не расширяйте это заявление на другие версии Qwen Code, провайдеры, модели или
каналы публикации без новой ограниченной проверки реального хоста, калибровки
расхода, проверки маскирования, обновления матрицы поддержки и финального
подтверждения жизненного цикла.
