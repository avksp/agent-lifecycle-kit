# Переносимый пакет Agent Plugins

ALK публикует поддерживаемые навыки в переносимом формате для клиентов,
которые реализуют [спецификацию Agent Plugins](https://agent-plugins.org/specification).
Это дополнительный способ доставки навыков ALK. Он не заменяет пакет Python,
проекции адаптеров и команды жизненного цикла.

## Состав пакета

Архив релиза содержит один корневой манифест и канонический набор навыков ALK:

```text
agent-lifecycle-kit-agent-plugin-v1.70.0.zip
├── plugin.json
└── skills/
    ├── agent-first-planning/SKILL.md
    ├── agent-plan-to-workers/SKILL.md
    ├── agent-workflow-orchestrator/SKILL.md
    ├── audit-agent-plan/SKILL.md
    ├── audit-plan-implementation/SKILL.md
    ├── bug-forensics/SKILL.md
    └── issue-to-spec/SKILL.md
```

Корневой манифест соответствует договору Agent Plugins 1.0.0 и содержит версию
релиза. Каталог `skills/` создаётся из единственного источника — каталога
`skills/` в репозитории.

## Установка через совместимый клиент

Скачайте архив из [релиза на GitHub](https://github.com/avksp/agent-lifecycle-kit/releases/tag/v1.70.0), распакуйте его и выполните процедуру установки выбранного клиента. Спецификация задаёт состав пакета и структуру компонентов, а клиент определяет команду установки, запрос доверия, полномочия, обновление и локальный кэш.

Команды для конкретного клиента приведены в [руководстве по установке
адаптеров](../adapters/install.md) и на странице выбранного адаптера. Перед
установкой пакет можно проверить локально:

```bash
python tools/release/build_agent_plugin.py \
  --root . \
  --version 1.70.0 \
  --out work/agent-plugin \
  --archive work/agent-lifecycle-kit-agent-plugin-v1.70.0.zip

python tools/release/validate_agent_plugin.py \
  --package work/agent-plugin \
  --archive work/agent-lifecycle-kit-agent-plugin-v1.70.0.zip \
  --root . \
  --version 1.70.0 \
  --evidence work/agent-plugin-validation.json
```

Проверка сверяет локальный отпечаток схемы, манифест, обнаружение навыков,
обычные файлы, границы каталога и пути в архиве без обращения к сети или
модели.

После установки способом выбранного клиента используйте страницу [Проверка
Agent Plugins в клиентах](agent-plugin-qualification.md), чтобы выполнить
явную безопасную проверку Codex, Claude Code или Cursor. Полученная квитанция
связывает пакет с выбранным клиентом и не заменяет доказательство жизненного
цикла.

## Загрузка пакета и доказательство жизненного цикла

После загрузки пакета совместимым клиентом его навыки становятся доступны
этому клиенту. Сам факт загрузки навыка не создаёт спецификацию, не фиксирует
план, не разрешает изменения файлов и не формирует принятый аудит реализации.
Хост по-прежнему должен пройти жизненный цикл ALK и сохранить его артефакты:

1. уточнить запрос и создать спецификацию;
2. проверить и зафиксировать план вместе с lock-файлом;
3. выполнять только разрешённые пакеты задач;
4. сохранить квитанции проверок и подтверждений;
5. принять реализацию и сформировать итоговое доказательство.

[Руководство об источнике полномочий](source-of-truth.md) объясняет, какие
артефакты имеют силу. [Контракт публикации плагинов](plugin-publication.md)
описывает версии релизных поверхностей и правила обновления.

## Границы

- В пакет входят только навыки. В нём нет исходного кода ALK, состояния
  выполнения, задач проекта, секретов, ключей адаптеров и `mcp.json`.
- Пакет не запускает внешний CLI или модель. Запуск внешнего процесса остаётся
  явной функцией адаптера и локального профиля.
- Архив является проекцией релиза. Не редактируйте его вручную: изменяйте
  исходный каталог `skills/` и собирайте новый релиз.
- Версия пакета — неизменяемая семантическая версия. Манифесты плагинов для
  конкретных клиентов и проекции маркетплейсов остаются отдельными
  поверхностями публикации.
