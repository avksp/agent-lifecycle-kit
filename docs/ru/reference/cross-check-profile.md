# Дополнительный профиль перепроверки

Общий профиль перепроверки позволяет плану запросить дополнительную проверку
для рискованной задачи без включения проверки несколькими моделями в базовый
жизненный цикл.

`agent-cross-check-profile.v1` всегда:

- `OPTIONAL`;
- выключен по умолчанию;
- включается только явно;
- по умолчанию носит рекомендательный характер;
- становится обязательным только при явном включении в плане;
- ограничен по токенам, числу вызовов и времени выполнения;
- не является канонической поверхностью учёта `USD-cost`.

## Артефакты подтверждения

`agent-cross-check-receipt.v1` фиксирует предмет проверки, проверяющего,
выводы, подтверждение независимости, бюджетное ограничение и фактическое
использование. Валидация падает, если:

- отпечаток профиля не совпадает;
- фактическое использование превышает ограничение;
- обязательная перепроверка заявлена без явного включения в плане;
- независимость требуется, но не подтверждается нейтральными хэшами
  идентичности;
- реальные вызовы заявлены, но профиль их не разрешает;
- используются денежные поля бюджета.

Проверка независимости не зависит от провайдера: артефакт сравнивает только
`hostIdentityHash` и `modelIdentityHash`. Имена провайдеров, моделей и аккаунтов
не являются каноническими полями контракта.

Такой профиль полезен для задач `S2`, безопасности, релизов и исправления
ошибок, но обычные задачи остаются на стандартном пути жизненного цикла.

## Связь с групповой проверкой

Групповая проверка переиспользует этот профиль для бюджетов и проверки
независимости. Она добавляет режимы жизненного цикла и артефакты назначения,
результата, объединения выводов и кворума для нескольких проверяющих, но не
вводит отдельную модель бюджета и второй способ подтверждать независимость.
