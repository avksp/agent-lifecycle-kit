# Диагностические пакеты

Диагностический пакет экспортирует короткую обезличенную сводку по уже
существующим артефактам жизненного цикла. `agent-diagnostic-bundle.v1` содержит
идентификаторы артефактов, версии схем, статусы, количество блокеров и отпечатки
обезличенных сводок. Он не копирует полные подтверждения и не становится новым
источником правды.

Команда только читает входные артефакты, ограничивает количество файлов и размер
входа, а также отказывает при отсутствующем, повреждённом или слишком большом
артефакте.

```bash
agent-lifecycle diagnostics bundle \
  --artifact <evidence.json> \
  --out <diagnostic-bundle.json>
```

Используйте такой пакет для маршрутизации, разбора проблемы или передачи
сжатого контекста небольшой локальной модели. Финальная приёмка всё равно должна
проверять исходный план, подтверждения и аудит.
