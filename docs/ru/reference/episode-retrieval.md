# Поиск по прошлым эпизодам

Поиск по прошлым эпизодам — лёгкий механизм контекста поверх явно переданных
артефактов подтверждения или резюме сессий. Его можно пересобрать, он ограничен
по объёму и не является источником правды.

## Контракты

- `agent-episode-index.v1`: компактный индекс эпизодов по явно переданным путям
  артефактов.
- `agent-episode-index-validation.v1`: структурная проверка индекса.
- `agent-episode-retrieval.v1`: ограниченный результат поиска по запросу.

Индекс использует существующий индекс подтверждений и сохраняет происхождение
отпечатка для каждого эпизода. Результаты содержат `sourcePath`,
`artifactDigest`, компактное резюме и состояние цепочки.

## Учёт цепочки

Если передан `agent-receipt-hash-chain.v1`, эпизод получает `chainVerified`
только когда путь артефакта и отпечаток совпадают с записью в цепочке. Если
подходящей цепочки нет, поиск всё равно работает, но возвращает
`chainUnchecked: true`.

Это важно: поиск помогает подобрать контекст, но непроверенный результат поиска
не является доказательством.

## Python API

```python
from pathlib import Path

from agent_lifecycle.context import build_episode_context

context = build_episode_context(
    Path("."),
    ["final/final-proof.json", "reviews/task-review.json"],
    query="regression proof",
    max_results=4,
)
```

## Границы

- Поиск по прошлым эпизодам является дополнительным и запускается только явно.
- Он не читает произвольные пути; вызывающая сторона передаёт пути артефактов
  относительно репозитория.
- Он не возвращает исходное содержимое артефактов.
- Он падает закрыто, если результат превышает целевой бюджет контекста.
