# Вердикт проверки

Структурированный вердикт проверки даёт ALK короткий маршрут исправления, не
заменяя полный артефакт проверки. `agent-review-verdict.v1` разделяет четыре
области:

- соответствие требованиям;
- качество реализации;
- качество подтверждений;
- остаточный риск.

Каждая область имеет статус, код причины и краткое резюме. Маршрут указывает
следующее действие: принять, исправить реализацию, усилить подтверждения,
переоткрыть контракт или заблокироваться на внешнем действии.

```bash
agent-lifecycle audit review-check --review <task-review.json>
```

`agent-review-verdict-validation.v1` отказывает, если принятая проверка имеет
проваленную область, нерешённое замечание `MEDIUM+` или маршрут, который не
соответствует итоговому вердикту. Если `reviewVerdict` есть в
`agent-task-review.v2`, workflow проверяет его перед приёмкой задачи.
