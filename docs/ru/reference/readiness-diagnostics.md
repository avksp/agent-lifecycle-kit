# Диагностика готовности

`agent-lifecycle diagnose --no-install-plans` проверяет текущее дерево без
записи файлов и без реальных вызовов моделей.

## Что проверяется

- версия пакета и метаданные проекта;
- профили контекста и маршрутизации моделей;
- дескрипторы адаптеров;
- публичные резюме подтверждений;
- отсутствие заявлений, которые нельзя подтвердить текущими артефактами.

## Как читать результат

`PASS` означает, что текущее дерево внутренне согласовано. Это не заменяет
проверку конкретного релиза, реальную проверку адаптера или финальное
подтверждение задачи.

Если статус не `PASS`, нужно сначала закрыть блокеры из отчёта. Молчаливое
понижение требований не допускается.
