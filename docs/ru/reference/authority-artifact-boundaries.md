# Границы полномочий и артефактов

Проверка completeness принимает явный `operation_root` для проверки деклараций с учётом файловой системы. Без него PASS подтверждает только автономную структурную проверку. Запуск задачи и выбор следующего действия получают корень из загруженного состояния через `package_root` и проверяют полный набор деклараций владения до выделения попытки или предложения действия. Аудит пакета выполняет эту проверку с явным `project_root` (либо прежним значением по умолчанию — текущим каталогом), включая старые lock-файлы без package integrity.

Проверка компилятора охватывает все файлы пакетов и индекс до создания каталогов. Защищённая запись с привязкой к корню продолжает обеспечивать изоляцию после предварительной проверки. Структурный отчёт completeness без корня не даёт полномочий на операции с файловой системой.
