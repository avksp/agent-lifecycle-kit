# Исторические записи восстановления runner

Квитанции восстановления runner являются историческим подтверждением, а не
контроллером выполнения. В релизе 2.0 их схемы остаются читаемыми, чтобы старый
архив можно было преобразовать без выдачи ему полномочий.

Используйте `workflow migrate-runner-artifact` для явного read-only
преобразования. Конвертер ограничивает размер входа, проверяет дайджест,
сохраняет исходный файл, создаёт одну приватную запись без замены и фиксирует
неперенесённые поля вместо догадок о состоянии workflow. Результат
неавторитетен и не может разрешить повтор, возобновление или production-действие.

Текущее восстановление принадлежит состоянию workflow: истории попыток задач,
review задачи, `REWORK`, паузе/возобновлению внешнего действия и маршруту
финального аудита. Нужно начинать с текущего состояния workflow и замороженного
плана, а не восстанавливать полномочия из исторического снимка runner.

Совместимый путь обязателен на всей ветке 2.x. Его удаление потребует отдельного
аудита совместимости и решения для мажорной версии не ранее 3.0.
