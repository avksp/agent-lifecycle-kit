# Бюджет контекста для расследования ошибок

Профиль расследования ошибок должен помещаться в компактный контекст без
копирования больших логов. Бюджет задаётся в токенах и ресурсах, обязательный
`USD-cost` не нужен.

В компактный пакет включаются:

- активная задача по багу и критерии приёмки;
- команда воспроизведения, которая падает, и короткий шаблон ошибки;
- поля отпечатка ошибки и отпечаток;
- журнал гипотез, максимум 12 записей;
- область подозреваемого кода, границы записи и обоснование минимальной правки;
- отпечаток основной причины и отпечаток артефакта влияния правки;
- команда регрессионной проверки до и после фикса;
- отпечаток дополнительной перепроверки, если она была включена планом.

Ограничения по умолчанию:

- активный пакет: 9000 токенов;
- резюме подтверждений: 4000 токенов;
- записи журнала гипотез: 12;
- ссылки на отпечатки артефактов: 20.

Полные логи остаются файлами артефактов. В контекст достаточно включать путь,
sha256, размер в байтах, верхний кадр стека, исключение или утверждение и
стабильный шаблон лога.

Рецепты должны помещаться в тот же компактный пакет: идентификатор выбранного
рецепта, этап, обязательные схемы артефактов и короткий чек-лист. Полные логи,
выводы команд и подробные отвергнутые гипотезы остаются артефактами со ссылками
на отпечатки.
