# Источник правды

Agent Lifecycle Kit различает рабочие представления и источник правды.
Рабочие представления помогают агенту читать состояние, но не заменяют
зафиксированные артефакты.

## Правило документации

Документация объясняет поведение, но не является доказательством выполнения.
Для заявлений о релизе, зрелости адаптера или завершении задачи нужны
структурированные артефакты и проверки.

## Правило доказательств

Финальное завершение опирается на план, критерии приёмки, отчёты выполнения,
проверку реализации, completion gate и финальное подтверждение. Если данных не
хватает, процесс останавливается и требует явного решения.

## Правило входящих задач

Внешние issue, тикеты и импортированные payloads являются только draft input.
Они могут помочь подготовить спецификацию, но не разрешают выполнение, не
фиксируют план и не заменяют проверенные ALK source-of-truth артефакты.
