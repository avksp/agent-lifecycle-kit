# Экспорт использования

`agent-lifecycle metrics usage-export` строит экспорт без записи из явно
переданных локальных JSON-артефактов. Команда не запускает реальные вызовы
хостов и не переводит использование локальных моделей в деньги.

Экспорт включает:

- идентификаторы адаптера, сессии, запуска, задачи и операции;
- отпечатки подтверждений, найденные в исходных артефактах;
- входные, выходные и общие токены;
- шаги, длительность и ресурсные единицы, например байты контекста или вызовы
  инструментов;
- необязательные решения по бюджету;
- необязательный `cost_usd` только как значение, сообщённое тарифицируемым
  хостом.
- `usageConfidence`: `ATTESTED`, `ESTIMATED`, `MISSING` или `INVALID`.

Состояние `ATTESTED` требует одновременно `attestation.source: host` и
`attestation.status: ATTESTED`. Оценка ядра или подтверждение из тестового
образца остаётся `ESTIMATED`, даже если содержит точные числа для своего
исходного артефакта.

`cost_usd` не является каноническим учётом. Общий переносимый слой — это токены
и ресурсы. Ядро не содержит каталога тарифов и не оценивает денежный расход
локальных моделей.

```bash
agent-lifecycle metrics usage-export \
  --artifact work/run/model-usage.json \
  --project-root . \
  --format json \
  --out work/run/usage-export.json

agent-lifecycle metrics usage-export \
  --artifact work/run/model-usage.json \
  --format table \
  --out work/run/usage-export.txt
```

Выходные файлы создаются только один раз. Строковые поля из исходных артефактов
перед проверкой маскируются от локальных абсолютных путей и типовых секретных
маркеров.

Состояния нормализаторов и правила приёмки для S1/S2 описаны в разделе
[Локальный учёт токенов хоста](host-local-token-accounting.md).
