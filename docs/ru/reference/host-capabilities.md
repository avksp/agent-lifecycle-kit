# Возможности хоста

Возможности хоста описывают, что адаптер может предоставить ALK без привязки
поведения к имени провайдера или модели.

`agent-host-capability.v1` — расширяемое объявление в дескрипторах адаптеров и
манифестах возможностей. Для `acp` действуют правила:

- `support` принимает `supported`, `unsupported` или `unknown`;
- `providerIdentityUsed` всегда `false`;
- `supported` требует `transport: "acp"`, `evidencePolicy:
  "probe-required"` и контракт вызова через
  `agent-host-operation-request.v1` / `agent-host-operation-receipt.v1`;
- проба хоста является безопасной предварительной проверкой и не запускает
  реальные вызовы модели;
- отсутствующий исполняемый файл, неуспешная проба или неверный контракт
  блокируют положительное объявление.

Хосты без подтверждения пробы должны быть представлены как `unsupported`,
`unknown` или не входить в положительный набор возможностей.

## Осмотр пакетов адаптеров

`tools/release/discover_adapter_packages.py` ищет `adapter.descriptor.json` и
`capabilities.manifest.json` в пакетах адаптеров. Результат является
рекомендательным:

- дескриптор остаётся источником правды по уровню поддержки адаптера;
- манифест возможностей остаётся источником правды по операциям;
- осмотр не устанавливает уровень поддержки адаптера;
- команда не запускает хост и модель.
