# Проверка Agent Plugins в клиентах

[English version](https://github.com/avksp/agent-lifecycle-kit/blob/main/docs/reference/agent-plugin-qualification.md)

ALK публикует переносимый пакет Agent Plugins с семью поддерживаемыми навыками
жизненного цикла. Проверка клиента отвечает на более узкий вопрос: может ли
выбранный клиент обнаружить пакет, который установил оператор.

## Что проверяется

Квитанция проверки связана с:

- точной версией и отпечатком пакета;
- выбранным профилем клиента и его отпечатком;
- обнаруженной версией клиента;
- проекцией `plugin.json` и семью каноническими навыками;
- результатом двух безопасных команд клиента, если выполнена проверка
  установленного пакета.

Клиент отвечает за установку, запрос доверия, полномочия, обновление и
локальный кэш. ALK не устанавливает плагин и не изменяет настройки клиента.

## Офлайн-проверка

Соберите и проверьте пакет без запуска клиента:

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src python3 tools/release/build_agent_plugin.py \
  --root . \
  --version 1.69.0 \
  --out work/release-1-69/agent-plugin \
  --archive work/release-1-69/agent-lifecycle-kit-agent-plugin-v1.69.0.zip

PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src python3 \
  tools/release/validate_agent_plugin_qualification.py \
  --package work/release-1-69/agent-plugin \
  --profile adapters/codex/agent_plugin_profile.json \
  --version 1.69.0 \
  --evidence work/release-1-69/evidence/offline.json
```

В этом режиме не запускаются процессы клиента и не выполняются вызовы модели
или сети. При совпадении пакета и профиля результатом будет
`OFFLINE_VALIDATED`.

## Проверка после установки

Установите пакет штатным способом выбранного клиента. Затем запустите проверку
ALK с профилем этого клиента:

```bash
agent-lifecycle adapter plugin-qualify \
  --adapter codex \
  --profile adapters/codex/agent_plugin_profile.json \
  --package work/release-1-69/agent-plugin \
  --project-root . \
  --out work/release-1-69/evidence/codex-qualification.json
```

Проверка выполняет только команды версии и справки, указанные в профиле. Для
них используются `shell=False`, точный список разрешённых переменных окружения,
лимит десять секунд на команду и ограничение объёма вывода. Квитанция хранит
отпечатки, размеры, версии и статусы; запросы, полный вывод клиента, секреты и
абсолютные пути в неё не попадают.

Результат имеет один из статусов:

- `QUALIFIED` — пакет и проекция клиента найдены, обе безопасные команды
  завершились успешно;
- `OFFLINE_VALIDATED` — проверен только пакет;
- `BLOCKED` — пакет, проекция или сведения о версии не соответствуют профилю;
- `UNAVAILABLE` — исполняемый файл выбранного клиента недоступен.

Квитанция относится только к названному клиенту и профилю. Она не доказывает
выполнение жизненного цикла ALK, наличие проверенного плана, управляемый запуск
клиента или повышение уровня поддержки адаптера. Для таких заявлений нужны
соответствующие артефакты и гейты ALK.

## Профили

В релиз входят профили без исполняемой логики для Codex, Claude Code и Cursor.

Проверьте все профили одной командой:

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src python3 \
  tools/release/validate_agent_plugin_profiles.py \
  --profiles adapters/codex/agent_plugin_profile.json \
             adapters/claude/agent_plugin_profile.json \
             adapters/cursor/agent_plugin_profile.json \
  --evidence work/release-1-69/evidence/profiles.json
```

Профили не могут изменять уровень зрелости адаптера или значение
`managedLaunch.status`.
Каждый профиль также содержит политику версии клиента. В поставляемых
профилях используется `mode: reported` и `accepted: any-version`: обнаруженная
версия записывается в квитанцию, но сама по себе не означает неограниченную
поддержку клиента и не даёт подтверждения жизненного цикла.

Профиль и квитанция проверки являются отдельными версиями контрактов, которые
непосредственно проверяют команды квалификации. Они намеренно отделены от
общего каталога контрактов жизненного цикла.
Поставляемые профили используют режим наблюдения. Для закрытого диапазона
версий потребуется отдельная реализованная и проверенная политика.
