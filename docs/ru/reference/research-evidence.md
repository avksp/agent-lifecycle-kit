# Проверка исследовательских материалов

[English version](https://github.com/avksp/agent-lifecycle-kit/blob/main/docs/reference/research-evidence.md)

Исследовательские материалы — это ограниченный пакет для технического
исследования, анализа архитектуры и подготовки плана. Он связывает источники,
утверждения, цитаты и происхождение данных до передачи материалов в рабочий
процесс ALK.

Пакет содержит дополнительный контекст. Источником решений ALK остаются
проверенная спецификация, зафиксированный план, критерии приёмки и
подтверждения реализации.

## Обычный порядок работы

1. Адаптер или оператор формирует `research-evidence.json` из выбранных
   источников. Для каждого утверждения указываются источник и цитата.
2. Оператор передаёт ALK пакет и явные снимки источников в кодировке UTF-8,
   если нужно проверить цитируемые фрагменты.
3. ALK проверяет связи, отпечатки, происхождение, статус материалов,
   ограничения размера и безопасность без сети, вызова модели и запуска
   внешнего процесса.
4. ALK создаёт подтверждение проверки и ограниченную сводку. Сводку можно
   приложить к черновику спецификации или плана для последующего рассмотрения.

## Команды

Проверка пакета и цитаты по локальному снимку источника:

```bash
agent-lifecycle research validate \
  --package work/research/research-evidence.json \
  --snapshot source-1=work/research/snapshots/source-1.txt \
  --out work/research/validation.json
```

Создание краткой сводки по пакету и подтверждению проверки:

```bash
agent-lifecycle research summary \
  --package work/research/research-evidence.json \
  --validation work/research/validation.json \
  --out work/research/summary.json
```

Путь результата записывается один раз. Для нового запуска указывайте новый
путь, чтобы прежнее подтверждение нельзя было незаметно заменить.

## Состав пакета

| Запись | Назначение |
| --- | --- |
| Источник | Хранит происхождение, тип, ссылку, отпечаток источника и необязательный отпечаток снимка. |
| Утверждение | Формулирует один ограниченный вывод и связывает его с источниками и цитатами. |
| Цитата | Связывает утверждение с источником и, при наличии снимка, с диапазоном UTF-8 и его отпечатком. |
| Связь происхождения | Описывает отношение `seed`, `derived-from`, `duplicate-of` или `suggested-by` между источниками. |
| Ограничения ресурсов | Ограничивают размер пакета и количество записей до начала обработки. |
| Редакция | Подтверждает, что исходный текст и чувствительные значения не хранятся в переносимом пакете. |

Публичные схемы пакета:

- `agent-research-source.v1`
- `agent-research-claim.v1`
- `agent-research-citation.v1`
- `agent-research-provenance-edge.v1`
- `agent-research-evidence-package.v1`
- `agent-research-evidence-validation.v1`
- `agent-research-evidence-summary.v1`

## Как читать результат

Команда `research validate` создаёт подтверждение проверки:

- `PASS` означает, что структура пакета корректна, связи и переданные снимки
  совпадают, в графе происхождения нет блокирующего цикла и проверки
  безопасности пройдены.
- `FAIL` содержит ограниченный список `blockers` со стабильными кодами. До
  устранения причины или замены пакета не следует считать материалы принятыми.
- `UNAVAILABLE` означает, что снимок источника для цитаты не передан. Пакет
  может оставаться структурно корректным, но сводка покажет пробел и не будет
  считать такое утверждение подтверждённым.
- `MISMATCH` фиксирует заявленное расхождение и не превращается в проверенную
  цитату.

Сводка содержит `supportedClaims`, `evidenceGaps`, группы дубликатов и
распределение статусов. В ней есть идентификаторы и отпечатки, но нет исходных
документов, стенограмм и промптов.

## Происхождение и независимость

Копии и материалы, созданные на основе одного источника, обозначаются как
`duplicate-of` или `derived-from` и не считаются независимыми источниками.
Цикл в графе происхождения блокирует проверку, потому что исходная точка
становится неоднозначной. Несвязанные источники показываются отдельно, чтобы
проверяющий мог отличить независимые материалы от набора несвязанных ссылок.

## Граница безопасности

Исследовательский пакет считается недоверенным входом. Проверка отклоняет
исходные поля с текстом документа, поля провайдера или модели, маркеры команд
для управления промптом, признаки секретов и локальные абсолютные пути.
Ссылки в локаторах являются только метаданными: ALK не загружает URL, не
открывает произвольные пути и не выполняет инструкции из текста источника.

Исследовательские материалы не меняют план, не принимают задачу, не закрывают
гейт аудита и не подтверждают готовность к эксплуатации. Модель или хост могут
использовать сводку для подготовки требований, но проверка спецификации и
фиксация плана остаются обязательными.

## Ограничения

По умолчанию размер пакета и снимка ограничен 32 МиБ. Допускается не более
128 источников, 256 утверждений, 256 цитат и 512 связей происхождения. Для
большого исследования используйте несколько проверенных пакетов, а не
встраивайте исходные документы в метаданные.

См. [публичные контракты](public-contracts.md) и [руководство по работе с
исследованием](../guides/research-workflow.md).
