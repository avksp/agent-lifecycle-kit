# Controlled technical English for ALK

This local STE-inspired profile claims no ASD-STE100 conformity or certification.
It does not reproduce the licensed manual or dictionary. Russian preserves meaning.

## Write an instruction

Name the actor; use an active verb. Put the condition before one action per
sentence. Use one term per concept. Explain unfamiliar terms. Use MUST for an
obligation, MUST NOT / “do not” for a prohibition, MAY for an option; do not
weaken MUST to “should”. State the evidence and refusal condition. Preserve
exceptions, negations and ordering. Keep commands, paths, fields, enums, errors,
hashes, units and limits exact. Shorter text must not grant authority.

## ALK glossary

Draft grants no execution authority. A frozen plan binds reviewed matching inputs
by lock; freeze alone does not authorize. Authorization permits the selected
native action. An attempt is bounded and retains retry costs. A receipt binds
inputs and operation; existence alone proves no acceptance. Evidence supports
only its stated claim. Independent review excludes author self-review.
Acceptance is the existing gated workflow transition. Projection grants no
authority. Refusal means stop, never success. Budgets remain finite through
compact/retry. `UNKNOWN` / null remains unknown, never measured zero.

## Read by stage

Read the complete hash-bound role contract, latest user instruction and active
packet verbatim. Resolve paths from the installed skill root. The package supplies
its static resources. For recipe roles read cookbook PREFACE, Canonical execution
route, Choose a recipe, Safety rules, selected recipe and mandatory follow-ups.
Load another recipe only when the stage changes. Compilation and intake use their
complete contracts without borrowing unrelated recipes. The orchestrator selects
its actual stage. See [Lifecycle task scenarios](lifecycle-cookbook.md).

## Assign a suitable role

Before assigning researcher, worker, reviewer or final auditor, the controller
records risk, required tools, data policy, context/output limits and usage evidence
requirements in existing plan/packet inputs. Use provider-neutral classes and
existing host-local profiles/evidence. A compact worker is not a qualified critical
reviewer. Preserve independence, AC and quality floor despite price or window.
If no suitable reviewer satisfies local-only policy, stop; do not silently fall
back to cloud. Packet bytes do not measure full host input: if that input is
unknown, strict fit is unproven. Keep `UNKNOWN` / null and all expense history.
Check binding and freshness before assignment. Changed model, host or configuration
requires refreshing only affected qualification; an unchanged qualified route uses
short preflight, no new benchmark or automatic expensive fresh review. This is
guidance, not a selector, schema, gate or proof of host enforcement.

## Measure and review

Parity guards check hashes, package bytes and bounded clauses, not arbitrary
meaning, model behavior or general STE compliance. Count UTF-8 intervals and
whitespace words (`len(text.split())`), including Markdown/code; these are not
tokens, model calls or cost. Retain exact before/after bytes/hashes and the same
stage. Include complete role/shared contracts and all mandatory transitive links.
Union overlapping intervals per document/case; count reuse in each other case.
Missing sources mean `INCOMPLETE`. Report increases. Do not omit obligations or
assume reuse after compact to improve counts. User/system/packet/host input is
outside this projection. Equal S0/S2 authoring bytes do not imply equal workflow
cost. Independent semantic review checks actor, condition, action, refusal,
MUST/MAY, UNKNOWN, commands and schemas. Token savings and model behavior remain
UNAVAILABLE without comparable measured evidence.
