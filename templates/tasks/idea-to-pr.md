# Idea To PR Task Template

Template status: DRAFT-ONLY.
Review gate: required.
Freeze gate: required.
Runtime defaults: none.

## Draft Inputs

- User goal: `{{goal}}`
- Current behavior: `{{current_behavior}}`
- Desired behavior: `{{desired_behavior}}`
- Constraints: `{{constraints}}`
- Validation target: `{{validation_target}}`

## Draft Requirements

- Clarify the smallest useful scope.
- Map affected modules and ownership.
- Define acceptance criteria before code changes.
- Implement the narrowest coherent change.
- Run focused validation and update relevant docs.

## Draft Evidence

- Plan review result.
- Focused test or command output.
- Changed-file summary.
- Residual risk note.
