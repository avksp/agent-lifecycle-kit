# Agent Lifecycle Kit v0.14.0 Notes

Status: source release.

## Highlights

- Updated package metadata to `0.14.0`.
- Added specification-level `completionCheck` support.
- Added `agent-completion-check.v1` and
  `agent-completion-check-receipt.v1` schemas.
- Finalization now fails closed when a declared completion check is missing,
  unbound to the current run, missing required evidence, or reports `FAIL`.
- Human-decision completion checks bind to the existing
  `agent-external-action-receipt.v1` path.
- Renamed the synthetic replay quality key to `qualityCheck`.

## Scope

This release does not promote any additional adapter. It adds a provider-neutral
observable completion contract and keeps `productionPromotionClaimed: false` for
source-release evidence.
