# Agent Lifecycle Kit v0.18.0 Notes

Status: source release.

## Changes

- Updated package metadata to `0.18.0`.
- Added neutral adapter event capture declarations for current adapter
  descriptors and capability manifests.
- Added `agent-adapter-event-stream-receipt.v1` and
  `agent-adapter-event-capture-validation.v1`.
- Added `agent-lifecycle adapter event-capture-check` for receipt-bound event
  stream validation.
- Added conformance fixtures and checks so declared event capture fails closed
  when event streams or receipts are missing, malformed or stale.
- Added failed-command and false-completion checks for `agent-adapter-event.v1`
  streams.
- Added `agent-review-verdict.v1`,
  `agent-review-verdict-validation.v1` and
  `agent-review-routing-summary.v1`.
- Added `agent-lifecycle audit review-check` and workflow validation for
  structured task review verdicts when present.

## Safety

- Event capture declarations do not change adapter maturity.
- Event stream receipts set `productionPromotionClaimed` to `false`.
- Review verdict summaries are compact routing aids; full review and evidence
  artifacts remain authoritative.
