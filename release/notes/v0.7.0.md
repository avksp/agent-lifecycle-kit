# Agent Lifecycle Kit v0.7.0 Notes

Status: source release.

## Highlights

- Added adapter capability manifests and offline conformance verification.
- Added `agent-lifecycle adapter inspect` for safe host capability discovery
  without starting live model calls.
- Extended adapter scaffolding with capability manifests, fail-closed runner
  skeletons, receipt normalizers, tests and support stubs.
- Recorded OpenCode 1.18.9 safe inspection and offline conformance evidence.

## Scope

OpenCode remains `EXPERIMENTAL`. This release does not claim live host
conformance, usage calibration, lifecycle proof, npm publication, public
directory approval, or production promotion for OpenCode.

Current blocker: host-local model bindings and live harness proof are not yet
accepted for OpenCode.
