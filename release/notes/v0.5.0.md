# Agent Lifecycle Kit v0.5.0 notes

Status: source release.

This release adds the release-0-5 execution gates for honest task completion:
frozen acceptance checklist validation, neutral adapter event streams,
task-acceptance write-scope enforcement, per-attempt baseline reconciliation,
external-action parking, and final completion signals.

Claude Code is host-specific `VERIFIED` for Claude Code 2.1.220 after local
live host conformance, live calibration, and full ALK lifecycle proof evidence.
Codex, Cursor, Hermes, and OpenCode remain `EXPERIMENTAL` until each host has
matching live evidence. Public directory approval and broader production
promotion are not claimed.

## Added

- `adapter.event.v1` validation for neutral host progress and terminal task
  event semantics.
- Acceptance checklist validation against frozen manifests before plan freeze
  evidence can be accepted.
- Task acceptance enforcement bound to write-scope receipts.
- Per-attempt baseline reconciliation so task attempts cannot silently drift
  from the expected source revision.
- `WAITING_FOR_EXTERNAL_ACTION` parking and final completion-signal evidence.

## Adapter maturity

- Claude Code is `VERIFIED` only for the tested Claude Code 2.1.220 host range.
- Other bundled host projections remain `EXPERIMENTAL`.

## Budget modes

- `metered` requires an approved USD cap.
- `subscription` requires `maxInvocations` and a token or wall-clock cap.
- `local` follows the same resource-cap rule as `subscription`.

Budget caps stop runaway execution and force an operator or policy decision.
They do not prove production promotion by themselves.
