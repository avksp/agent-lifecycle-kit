# Agent Lifecycle Kit v1.0.0 Notes

## Summary

Agent Lifecycle Kit 1.0.0 stabilizes the public contract surface while keeping
adapter maturity evidence-bound. The release adds compact contract policy
checks, lifecycle cost accounting, resource/security guidance and stable package
metadata.

## Changes

- Added `agent-public-contract-policy.v1` and
  `agent-public-contract-policy-validation.v1`.
- Added `agent-lifecycle contract policy/check`.
- Added `agent-lifecycle-cost-report.v1`,
  `agent-lifecycle-cost-validation.v1` and `agent-lifecycle metrics
  cost-check`.
- Added documentation for public contracts, lifecycle cost accounting, and
  production resource/security use.
- Added release security tests for local-path leakage, secret markers and
  verified adapter evidence claims.
- Updated package and plugin metadata to `1.0.0`.

## Verification

- `python -m unittest discover -s tests -v`
- `PYTHONPATH=src python -m agent_lifecycle contract check`
- `PYTHONPATH=src python -m agent_lifecycle.neutrality scan --scope current-tree-complete --policy policy/neutrality.policy.json --require-zero-findings`

This release does not claim public marketplace approval or universal adapter
runtime support.
