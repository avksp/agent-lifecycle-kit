# Agent Lifecycle Kit v0.4.0 Notes

Status: source release.

This release adds host-local model selection and budget decision controls while
keeping portable core routing provider-neutral. Bundled adapters remain `EXPERIMENTAL`;
`VERIFIED` still requires live host conformance, live
calibration, neutrality, CI matrix, and independent final audit evidence.

## Added

- `agent-host-model-selection-profile.v1` validation for host-local mappings
  from neutral model classes to concrete host models.
- `agent-host-model-selection-receipt.v1` evidence from live host harnesses,
  with provider model names redacted to binding hashes.
- Budget decision workflow support for `WAITING_FOR_BUDGET_DECISION`, manual
  operator choices, bounded auto-reroute, and critical-review downgrade guards.
- CLI support for budget policy validation and budget decision recording.
- Host harness model flags and profile loading for Codex, OpenCode, Claude
  Code, and Hermes, with Cursor compatibility validation kept fixture-capable
  while release 0.3 Cursor live calibration remains blocked externally.
- Release 0.4 candidate validation for schema authority, host profile coverage,
  portable provider-model leakage, budget decision coverage, negative-suite
  coverage, neutrality, and compact-context task packet fit.

## Budget Modes

- `metered` requires an approved USD cap.
- `subscription` requires `maxInvocations` and a token or wall-clock cap.
- `local` follows the same resource-cap rule as `subscription`.

Budget caps stop runaway execution and force an operator or policy decision.
They do not prove production promotion by themselves.
