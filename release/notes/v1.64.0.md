# Agent Lifecycle Kit v1.64.0

Status: source release.

This release adds typed context checkpoints for reliable continuation after
context compaction, session interruption or an explicit recovery request.
Checkpoints preserve bounded lifecycle context without granting themselves
implementation authority.

## Changes

- Added typed checkpoint and continuation contracts with lineage, digest and
  bounded-size validation.
- Added milestone, agent-requested, adapter-hook and unavailable capture
  modes.
- Added adapter-owned evidence requirements for native-hook checkpoints,
  including accepted capture and receipt digests.
- Added contained local storage with atomic writes, idempotent retries,
  conflict detection and bounded retention.
- Added lifecycle checkpoint gates and CLI integration for explicit, opt-in
  checkpoint creation and restoration.
- Added English and Russian documentation for checkpoint workflows and
  recovery after context compaction.
- Updated plugin manifests, marketplace references and package metadata to
  version 1.64.0.
