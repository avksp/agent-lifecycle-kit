# Agent Lifecycle Kit v0.12.4 notes

Status: source release.

## Highlights

- Updated package metadata to `0.12.4`.
- Hardened Gemini CLI headless live commands with `--skip-trust`.
- Corrected Kimi Code headless live commands by removing the incompatible
  `--plan` flag and enforcing post-invocation clean-worktree checks.
- Updated adapter docs, evidence summaries, README, Russian README, and support
  matrix with the current live blockers.

## Scope

This patch does not promote Gemini CLI or Kimi Code to `VERIFIED`. Gemini CLI is
currently blocked by an unsupported Gemini Code Assist client tier on the local
host. Kimi Code is currently blocked until a provider/model alias is configured.
Both still require accepted live host conformance, live calibration, and ALK
lifecycle final proof evidence before promotion.
