# Agent Lifecycle Kit v0.16.0 notes

Status: source release.

## Changes

- Updated package metadata to `0.16.0`.
- Added `agent-runner-policy.v1`, `agent-runner-state.v1`,
  `agent-runner-transition-request.v1`, `agent-runner-transition-result.v1`
  and `agent-runner-snapshot.v1` schemas.
- Added provider-neutral runner core transitions for attempt, validate, review,
  accept, remediate, reroute, split, block and abort.
- Added `agent-lifecycle runner start`, `runner status`,
  `runner transition`, `runner stop` and `runner resume`.
- Added bounded attempt, reroute, split and billable-token guards.
- Added fail-closed patch metadata validation for remediation paths.
- Added runner architecture docs and extension points for later worktree and
  host-event integration.

## Safety

- Runner state does not replace workflow state; it records only execution-loop
  progress and transition history.
- Mutating runner commands require expected runner revisions and operation ids.
- Compact runner snapshots are validated under small-context limits, including
  `4k-strict`, while full workflow, evidence and review artifacts remain
  available for larger-model review.
- `productionPromotionClaimed` remains false for source-release evidence.
