# Agent Lifecycle Kit v1.63.2

Status: source release.

This patch release makes the first ALK run easier to discover and follow. It
adds a clear installation path for supported Python versions and platforms,
explains common `agent-lifecycle version` environment errors, and separates
the short quick start from the full command reference.

## Changes

- Added English and Russian installation guides for GitHub checkouts and PyPI
  on macOS, Linux and Windows PowerShell.
- Added task-oriented command references for planning, implementation, review,
  multi-model checks, progress, release validation and security checks.
- Added explicit host-plugin installation and prompt examples for Codex, Claude
  Code, OpenCode and other adapter-based hosts.
- Expanded the architecture documentation with the responsibilities of ALK,
  the host CLI, the model, the repository and the operator, including the
  guarantee chain and accepted lifecycle artifacts.
- Replaced informal lifecycle cookbook wording with professional lifecycle task
  scenario terminology in the documentation navigation.
- Extended documentation compatibility, onboarding and publication checks to
  cover the new pages and exact package pins.
