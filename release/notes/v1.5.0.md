# Agent Lifecycle Kit v1.5.0 Notes

Status: source release.

This release adds advisory lifecycle mode recommendations from accumulated cost
reports. The recommendation is intentionally conservative: it can point out
process overhead, but it does not change policy automatically and it does not
lower the required quality floor.

## Changes

- Added task-shape baselines for docs-only work, small fixes, features,
  releases, adapters and architecture work.
- Added overhead statistics across multiple lifecycle cost reports.
- Added `agent-lifecycle metrics recommend` with optional full JSON output and
  compact summary output.
- Added public schemas for baselines, baseline validation, overhead statistics,
  recommendations and compact recommendation summaries.
- Added fail-closed handling for invalid baselines and weak statistics.
- Updated package and plugin metadata to `1.5.0`.

## Validation

- Baseline validation tests cover repository defaults and invalid floor
  settings.
- Recommendation tests cover deterministic statistics, high-overhead small
  fixes, high-risk quality floors, weak statistics and compact summaries.
- CLI tests write recommendation artifacts and verify the compact summary with
  the small-context profile.
- Contract tests cover schema registry exposure and stable CLI output policy.

## Claims

- Adapter maturity changes: none.
- Production promotion claimed: false.
- Public directory or marketplace approval claimed: false.
