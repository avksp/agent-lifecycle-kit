# Agent Lifecycle Kit v0.12.3 Notes

Status: source release.

- Updated package metadata to `0.12.3`.
- Added bounded Gemini CLI and Kimi Code runners for host-operation requests.
- Added Gemini CLI and Kimi Code live harnesses that can normalize
  `stream-json` output into portable receipts under invocation, token, and

## Scope

`EXPERIMENTAL` until bounded live host conformance receipts, live calibration
receipts, and full ALK lifecycle proof evidence are accepted for the tested
host versions. Cursor also remains `EXPERIMENTAL`.
