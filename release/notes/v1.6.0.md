# Agent Lifecycle Kit v1.6.0 notes

Status: source release.

This release turns stable lifecycle recommendations into controlled policy
proposal artifacts. The default command path is read-only; applying a proposal
requires explicit approval through `--apply --output` and writes a new artifact
instead of editing existing policy files.

## Changes

- Added lifecycle policy proposal generation from recommendation reports.
- Added regression signal summaries for failed final audits, reopened work,
  rollback events and repeated remediation.
- Added `agent-lifecycle policy tune` with dry-run output, explicit apply output
  and compact proposal summaries.
- Added tuned policy artifacts with before/after values, rollback metadata,
  source proposal digests and preserved quality constraints.
- Added safeguards for low-confidence recommendations, invalid recommendation
  inputs, protected downgrades and blocking regression signals.
- Updated package and plugin metadata to `1.6.0`.

## Validation

- Policy proposal tests cover applyable low-risk changes, protected downgrade
  refusal, low-confidence refusal, regression blocking and compact summaries.
- Apply tests cover create-no-replace output and tuned policy rollback binding.
- CLI tests cover dry-run no-write behavior, explicit apply output and
  small-context summary fit.
- Contract tests cover the public schema registry and stable CLI output policy.

## Claims

- Adapter maturity changes: none.
- Production promotion claimed: false.
- Public directory or marketplace approval claimed: false.
