# Agent Lifecycle Kit v0.6.0 Notes

Status: source release.

## Highlights

- Codex CLI is host-specific `VERIFIED` for Codex CLI 0.145.0.
- Claude Code remains host-specific `VERIFIED` for Claude Code 2.1.220.
- Cursor, Hermes, and OpenCode remain `EXPERIMENTAL` until each host has
  matching live evidence.
- Public directory approval and broader production-promotion platform coverage
  are not claimed by this source release.

## What Changed

- Added committed redacted Codex CLI 0.6.0 evidence for live host conformance,
  live calibration, and one complete Agent Lifecycle Kit run.
- Made Codex live harness invocations ephemeral so release probes do not leave
  reusable host session state.
- Generalized release validation and support-matrix checks so Codex and Claude
  can both hold host-specific `VERIFIED` status without promoting other
  adapters.
- Updated package, plugin, marketplace, support-matrix, release-note, and
  install references for `v0.6.0`.

## Scope

The release keeps the release-0-5 execution gates: acceptance checklist
validation, neutral adapter event streams, task-acceptance write-scope
enforcement, per-attempt baseline reconciliation, external-action parking, and
final completion signals.

Budget caps stop runaway execution and force an operator or policy decision.
This remains separate from adapter maturity: cost controls help make work
efficient, but only live host evidence promotes an adapter to `VERIFIED`.
