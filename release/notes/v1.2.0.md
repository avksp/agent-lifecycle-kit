# Agent Lifecycle Kit v1.2.0 notes

## Summary

Agent Lifecycle Kit 1.2.0 adds optional evidence indexing and import helpers.
They reduce repeated context reads without becoming a new source of truth:
indexes are disposable and rebuildable, and imported planning inputs remain
draft-only until normal ALK review and freeze gates pass.

## Changes

- Added `agent-evidence-index.v1`.
- Added `agent-evidence-index-validation.v1`.
- Added `agent-evidence-search-summary.v1`.
- Added `agent-planning-import-result.v1`.
- Added `agent-planning-import-validation.v1`.
- Added `agent-skill-improvement-proposal.v1`.
- Added `agent-skill-improvement-proposal-validation.v1`.
- Added `agent-lifecycle evidence index`.
- Added `agent-lifecycle evidence search`.
- Added `agent-lifecycle import plan`.
- Added `agent-lifecycle import check`.
- Added `agent-lifecycle import proposal-check`.
- Updated package and plugin metadata to `1.2.0`.

## Verification

- `python -m unittest discover -s tests`
- `PYTHONPATH=src python -m agent_lifecycle contract check`
- `PYTHONPATH=src python -m agent_lifecycle.neutrality scan --scope current-tree-complete --policy policy/neutrality.policy.json --require-zero-findings`

This release does not add adapter targets, mandatory services or public
marketplace approval claims.
