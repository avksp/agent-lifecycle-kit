# Agent Lifecycle Kit v1.1.0 Notes

## Summary

Agent Lifecycle Kit 1.1.0 adds optional team-scale planning continuity. The
single-repository lifecycle remains the default, while coordinated work can
declare bounded repository references, freeze immutable plan snapshots,
reconcile current plans against saved snapshots and render compact reviewer
handoff packets.

## Changes

- Added `agent-plan-reference-validation.v1`.
- Added `agent-plan-snapshot.v1`.
- Added `agent-plan-reconciliation.v1`.
- Added `agent-plan-handoff.v1`.
- Added `agent-lifecycle plan refs-check`.
- Added `agent-lifecycle plan snapshot`.
- Added `agent-lifecycle plan reconcile`.
- Added `agent-lifecycle plan handoff`.
- Updated package and plugin metadata to `1.1.0`.

## Verification

- `python -m unittest discover -s tests -v`
- `PYTHONPATH=src python -m agent_lifecycle contract check`
- `PYTHONPATH=src python -m agent_lifecycle.neutrality scan --scope current-tree-complete --policy policy/neutrality.policy.json --require-zero-findings`

This release does not add adapter targets or public marketplace approval
claims.
