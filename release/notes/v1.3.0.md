# Agent Lifecycle Kit v1.3.0 Notes

Status: source release.

This release improves the public documentation surface and readiness reporting
without changing adapter maturity.

## Changes

- Reworked the English and Russian README files into compact entry points.
- Added quickstart, adapter installation, CLI reference, and source-of-truth
  pages.
- Added a tracked redacted adapter evidence summary index.
- Updated readiness diagnostics to distinguish missing tracked summaries from
  missing host-local raw receipts.
- Updated package and plugin metadata to `1.3.0`.

## Validation

- Documentation compatibility gates cover required maturity and contract
  markers.
- Readiness diagnostics tests cover separate evidence classification.
- Release security tests continue to block local absolute paths and secret
  markers in tracked text files.

## Claims

- Adapter maturity changes: none.
- Production promotion claimed: false.
- Public directory or marketplace approval claimed: false.
