# Agent Lifecycle Kit v0.17.0 Notes

Status: source release.

## Changes

- Updated package metadata to `0.17.0`.
- Added `agent-follow-up-register.v1`,
  `agent-follow-up-register-validation.v1`,
  `agent-follow-up-close-result.v1` and `agent-follow-up-summary.v1`.
- Added `agent-lifecycle followup check`, `followup add`, `followup close`
  and `followup sweep`.
- Added optional `workflow finalize --follow-up-register` proof binding and
  fail-closed finalization for open follow-up items that contradict current
  acceptance or completion proof.
- Added `agent-worktree-isolation-policy.v1`,
  `agent-worktree-attempt-receipt.v1` and
  `agent-worktree-attempt-receipt-validation.v1`.
- Added `agent-lifecycle worktree policy-check`, `worktree receipt` and
  `worktree check`.
- Updated user-facing adapter naming to `Qwen Code` while preserving stable
  machine ids and repository paths.

## Safety

- Follow-up records do not count as accepted evidence by themselves.
- Closed follow-up items must bind required evidence ids and current artifact
  identities.
- Worktree receipts preserve failed attempt artifacts by default and require
  explicit operator authorization for removal.
- `productionPromotionClaimed` remains false for source-release evidence.
