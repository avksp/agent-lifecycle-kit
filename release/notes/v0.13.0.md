# Agent Lifecycle Kit v0.13.0 notes

Status: source release.

## Highlights

- Updated package metadata to `0.13.0`.
- Added `agent-lifecycle diagnose` for one redacted readiness report over the
  checkout, package metadata, profiles, adapters, install plans, and evidence
  availability.
- Added `agent-readiness-report.v1` and `agent-adapter-install-plan.v1`
  schemas.
- Added `agent-lifecycle adapter install-plan` for dry-run adapter setup
  planning without host writes, live model calls, maturity changes, or
  promotion claims.
- Removed hard-coded source-release version references from user-facing install
  examples in README/support docs.

## Scope

This release does not promote any additional adapter. Diagnostics and install
planning are read-only by default and report `productionPromotionClaimed:
false`.
