# Agent Lifecycle Kit v0.6.1 Notes

Status: source release.

## Highlights

- Scaffold output now includes projection manifest, event bridge placeholder,
  and validation instructions for future host adapters.
- Added a reusable live-promotion runbook for host-specific `VERIFIED` claims.
- Added a verified-adapter release checklist that separates local tag, remote
  tag, GitHub Release object, CI status, docs gates, support-matrix gates, and
  source-release asset scope.
- Support-matrix validation now binds each `VERIFIED` host row to the evidence
  markers declared by that host's adapter descriptor.

## Scope

This patch does not change the Codex CLI 0.145.0 or Claude Code 2.1.220
host-specific `VERIFIED` claims. Cursor, Hermes, and OpenCode remain
`EXPERIMENTAL`.

Budget caps stop runaway execution and force an operator or policy decision.
Public directory approval, binary publication, and broader production-promotion
platform coverage are not claimed by this source release.
