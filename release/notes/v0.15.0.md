# Agent Lifecycle Kit v0.15.0 Notes

Status: source release.

## Changes

- Updated package metadata to `0.15.0`.
- Added `agent-goal-record.v1` and `agent-goal-record-validation.v1` for
  schema-backed goal continuity tied to workflow lineage.
- Added `agent-objective-snapshot.v1` and `agent-lifecycle goal summarize` for
  compact continuation state that carries concise working context, digests and
  next action instead of long duplicated history.
- Added `agent-lifecycle goal check` and `agent-lifecycle goal update` for
  validating and refreshing goal records without replacing workflow state.
- Added optional `workflow finalize --goal-record` binding so final proof can
  reference accepted work, `completionCheck`, and the current goal record.

## Safety

- Stale, mismatched, or contradictory goal records fail closed before
  continuation or final proof generation.
- Goal snapshots are validated against small-context limits, including
  `4k-strict`, while larger models can still use full plan, evidence, review
  and audit artifacts for quality-sensitive work.
- The release keeps provider-neutral naming and does not copy project-specific
  names from external research sources.
- `productionPromotionClaimed` remains false for source-release evidence.
