# Agent Lifecycle Kit v0.3.0 Notes

Status: source release.

This release line hardens offline source-release proof before any adapter is
promoted to `VERIFIED`.

## Added

- Shared workflow lineage checks for manifest, state, task packet index, final
  audit, final proof, release inventory, and lock identity.
- Final-candidate verification that parses evidence, rejects failed or malformed
  evidence, derives required tasks from the manifest, and fails closed on
  production-promotion overclaims.
- Release negative-suite coverage for `NEG-R03-01..NEG-R03-20`.
- Adapter descriptor validation through `HostOperationRequest` and
  `HostOperationReceipt`.
- Adapter scaffold generation for `EXPERIMENTAL` projection skeletons, with
  dry-run, existing-file, invalid-host, and no-`VERIFIED` guards.
- Live host conformance validation for promoted hosts, including per-operation
  host-protocol envelope checks and synthetic-replay rejection.
- Package type-marker support through `agent_lifecycle/py.typed`.

## Adapter Maturity

All bundled host projections remain `EXPERIMENTAL`. Live `VERIFIED` status still
requires host-bound install, lifecycle, usage, and calibration receipts.
